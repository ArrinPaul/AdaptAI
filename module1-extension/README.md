# Module 1 — Extension Core

This directory contains the Chrome Extension (Manifest V3) codebase for AdaptAI.

## Directory Structure (Planned)
- `manifest.json` — Manifest V3 configuration
- `onboarding.html` / `onboarding.js` — Onboarding landing page and accessibility tests UI
- `content.js` — DOM Analyzer, DOM Modifier, Read Aloud, Keyboard Nav, Voice Capture
- `background.js` — Event listener, chrome.storage manager, fetch client to Module 2 AI backend
